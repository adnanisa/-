# نموذج خدمة رفع دعوى قضائية

نموذج تفاعلي عربي (RTL) يدعم الدعوى الابتدائية والاستئناف والتمييز. يعمل بملفات ثابتة دون بناء أو خادم تطبيقات أو اتصال بجهات حكومية.

## التشغيل

افتح `index.html` في متصفح حديث مثل Microsoft Edge أو Chrome. جميع ملفات التشغيل في هذا المجلد، وجميع المسارات نسبية.

يمكن أيضًا تقديم المجلد عبر خادم ملفات محلي:

```text
python -m http.server 4173
```

ثم افتح http://localhost:4173. الحفظ مرتبط بعنوان الموقع والمتصفح؛ مسودات التشغيل من ملف محلي لا تنتقل تلقائيًا إلى نسخة GitHub Pages.

## الرفع إلى GitHub Pages

1. أنشئ مستودعًا، وارفع **محتويات هذا المجلد** إلى جذر المستودع بحيث يظهر `index.html` مباشرة فيه.
2. احتفظ بملفات JavaScript وCSS وSVG بجوار الصفحة، وأضف الملف `.nojekyll`.
3. من إعدادات المستودع: **Settings → Pages → Build and deployment → Source → Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم Save.
5. بعد اكتمال النشر، افتح رابط الموقع الذي تعرضه GitHub.

لا تحتاج إلى npm أو build أو GitHub Actions مخصص لتشغيل هذا النموذج.

مرجع إعداد مصدر النشر: [GitHub Docs](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

هذا التسليم يجهز الملفات فقط؛ لم يتم إنشاء مستودع خارجي أو رفعه أو نشره.

## تجربة سريعة

- ابدأ بـ«رفع دعوى جديدة»، ثم اختر أحد المسارات الثلاثة.
- من «إعدادات التجربة» أسفل الصفحة، استخدم «ملء الخطوة ببيانات تجريبية».
- في خطوة الموضوع، احفظ الموضوع الرئيسي لتظهر المحكمة.
- استعرض المحكمة الواحدة أو المتعددة أو حالات الفشل من إعدادات التجربة.
- للاستئناف استخدم `CASE-2026-1001`، وللتمييز `APP-2026-2001`.
- نتيجة الرسوم الافتراضية تعرض مبلغًا تجريبيًا قدره 78.500 د.ب. اختر «بدون رسوم» لتجربة زر التسجيل.
- الدفع لا يطلب بيانات بطاقة. تتوفر حالات النجاح والفشل والتعليق ونجاح الدفع مع تعذر التسجيل.
- «التحقق من حالة الدفع» يحاكي تسوية العملية المعلقة نفسها، ولا ينشئ عملية دفع جديدة.
- استخدم «حفظ والخروج» ثم «استكمال» لتجربة الاسترجاع.

## ما يعمل

- لوحة الطلبات: بحث، تصفية، استكمال، وحذف المسودات.
- خمس خطوات كاملة وروابط تعديل من الملخص.
- حقول الدور الشرطية: الوكالة والجهة الحكومية.
- مرجع مستقل للاستئناف أو التمييز مع حكم تجريبي قابل للاختيار.
- موضوع رئيسي واحد، وموضوعات فرعية بمبالغ منفصلة، ومرجع المقابلة/الضمان مرة واحدة.
- تحديد المحكمة بعد حفظ الموضوع، واختيارها تلقائيًا إذا كانت واحدة.
- إضافة الأطراف وتعديلها وحذفها مع جدول فوري.
- إرفاق ملفات تجريبية، والتحقق الأولي من الصيغة والحجم، وتنزيل المرفقات وحذفها.
- حفظ البيانات وملفات Blob في IndexedDB، مع رصد تعارض الحفظ من نافذتين.
- مراجعة وإقرار ورسوم، وفصل الدفع عن قيد الدعوى، وإيصال تجريبي.
- تصميم متجاوب ورسائل تحقق مرتبطة بالحقول ودعم لوحة المفاتيح.

## حدود النموذج

يبدأ النموذج بجلسة eKey2 **محاكاة**. لا توجد مصادقة أو صلاحيات قضائية أو تكامل فعلي مع نظام القضايا أو الوكالات أو الدفع.

التخزين محلي على المتصفح، وليس تخزينًا مؤسسيًا أو نسخًا احتياطيًا. لا تُرسل البيانات والمرفقات إلى GitHub أو الوزارة. إزالة بيانات الموقع أو استخدام جهاز آخر لا يسترجع المسودات السابقة. استخدم بيانات ومستندات تجريبية.

القوائم والتعرفة ونتائج المحاكم وأهلية الطعن أمثلة للعرض. قواعد المدد والإعفاءات والاختصاص وصلاحية الوكالة ومتطلبات الطعون تحتاج اعتمادًا وتكاملًا قبل التنفيذ الحقيقي.

تفاصيل الحقول والافتراضات ومصادر القواعد في `MODEL-AND-RULES.md`.

## الاختبارات للمطور

Node.js 20 أو أحدث:

```text
node --test tests.cjs
```

اختبارات المتصفح اختيارية للتطوير فقط. استخدمت Playwright 1.62.1 ومتصفح Edge:

```text
npm install --no-save playwright@1.62.1
node browser-tests.cjs
```

شغّل خادم الملفات على المنفذ 4173 قبل اختبار المتصفح. المتغير `PROTOTYPE_URL` يغير عنوان الاختبار، و`QA_DIR` يحدد موقع لقطات التحقق، و`BROWSER_CHANNEL` يغير قناة المتصفح (الافتراضي msedge).

لا تحتاج مكتبة الاختبار لتصفح النموذج أو رفعه إلى GitHub Pages.
