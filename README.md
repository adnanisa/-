# نموذج خدمة رفع دعوى قضائية

نموذج تفاعلي عربي (RTL) يدعم الدعوى الابتدائية والاستئناف والتمييز. يعمل بملفات ثابتة دون بناء أو خادم تطبيقات أو اتصال بجهات حكومية.

## التشغيل

افتح `index.html` في متصفح حديث مثل Microsoft Edge أو Chrome. جميع ملفات التشغيل في هذا المجلد، وجميع المسارات نسبية.

يمكن أيضًا تقديم المجلد عبر خادم ملفات محلي:

```text
python -m http.server 4173
```

ثم افتح http://localhost:4173. الحفظ مرتبط بعنوان الموقع والمتصفح؛ مسودات التشغيل من ملف محلي لا تنتقل تلقائيًا إلى نسخة GitHub Pages.

## الرفع إلى GitHub Pages

1. أنشئ مستودعًا، وارفع **محتويات هذا المجلد** إلى جذر المستودع بحيث يظهر `index.html` مباشرة فيه.
2. احتفظ بملفات JavaScript وCSS وSVG بجوار الصفحة، وأضف الملف `.nojekyll`.
3. من إعدادات المستودع: **Settings → Pages → Build and deployment → Source → Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم Save.
5. بعد اكتمال النشر، افتح رابط الموقع الذي تعرضه GitHub.

لا تحتاج إلى npm أو build أو GitHub Actions مخصص لتشغيل هذا النموذج.

مرجع إعداد مصدر النشر: [GitHub Docs](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

هذا التسليم يجهز الملفات فقط؛ لم يتم إنشاء مستودع خارجي أو رفعه أو نشره.

## تنسيق مشروع تنظيم حضور أطراف الدعوى

تستخدم الواجهة الهوية البصرية نفسها: خط Noto Kufi Arabic، وترويسة الوزارة مع علم البحرين، وشريط تنقل كحلي بخط أحمر، وأزرار وجداول وحقول متناسقة. يشمل التنسيق الصفحات وخطوات الطلب والتفاصيل والإيصال، مع تكييف العرض للجوال.

الخط مضمّن في `fonts.css` ويعمل دون خدمة خطوط خارجية. ارفع هذا الملف و`bahrain-flag.svg` وملف الترخيص `NotoKufiArabic-OFL.txt` مع بقية ملفات الحزمة. أرقام المسودات تبقى من 10 خانات مثل `3000221551`.

## تحديث ملاحظات V1 بتاريخ 16 نوفمبر 2026

- «ملفاتي» في التنقل و«ملفاتي القضائية» في العنوان والجدول، مع حذف مؤشر الطلبات المسجلة من الملخص العلوي.
- البحث في إشعارات التقديم برقم القضية فقط، والتصفية حسب الاستئناف/التمييز والمدة المتبقية؛ المتاح مرتب من الأقرب انتهاءً، ثم غير المتاح.
- جدول موحد للقضايا المرتبطة والمسودات، مع رقم القضية ونوعها والمحكمة والموضوع والحالة والتفاصيل.
- أرقام المسودات من 10 خانات مثل `3000221551`، مع الحفاظ على مفاتيح المسودات القديمة وروابطها. أرقام القضايا المقيدة والمرتبطة بصيغة `xx/xxxx/xxxxx/x`.
- ترتيب الموضوع: الرئيسي، ثم المواضيع الفرعية، ثم حفظ الموضوع والمحكمة المختصة.
- الرقم الشخصي يسترجع الاسم من محاكاة الإحصاء، والسجل التجاري من محاكاة السجلات التجارية، والهيئة الحكومية من قائمة الجهات.

التفاصيل وحالة كل ملاحظة في `V1-CHANGES.md`. قائمة أنواع الهوية الكاملة وشكل الاستعلامات العدلية الدقيق غير موجودين في المراجع المتاحة؛ النسخة تنفذ الأنواع الثلاثة المسماة في الملاحظات وجدول عرض مقترحًا، وتحتاج مطابقتهما مع المرجع الفعلي. الربط بالجهات محاكاة محلية فقط.

## الإضافات إلى واجهة رفع الدعوى

- تنظيم الطلب الرئيسي والطلبات الفرعية، مع مبلغ مستقل وإضافة وتعديل وحذف، وإلزامية تعتمد على نوع الدعوى وفق سياسة تجريبية.
- إشعارات بالمدة المتبقية للاستئناف والتمييز، وصفحة لاستعراض القضية وأحكامها والإجراء المتاح لكل حكم.
- بدء الطلب من الإشعار أو القضية، وتعبئة بيانات المرجع والحكم والطلبات المرتبطة تلقائيًا.
- عرض سبب عدم إتاحة التقديم عند انتهاء المدة أو عدم الأهلية أو نقص بيانات الموعد.
- ملخص مراجعة يعرض هيكل الطلب وبيانات القضية والحكم محل الطعن.

«الطلبات الفرعية» هي الموضوعات الفرعية المتفق عليها سابقًا في هذه النسخة. جميع المواعيد وشروط الإلزامية والأهلية أمثلة تحتاج اعتماد صاحب الخدمة.

## تجربة سريعة

- ابدأ بـ«رفع دعوى جديدة»، ثم اختر أحد المسارات الثلاثة.
- من لوحة ملفاتي جرّب «بدء استئناف» أو «عرض القضية والأحكام» للدخول المباشر.
- تاريخ المحاكاة الافتراضي 2026-11-12. غيّره في إعدادات التجربة لاستعراض اليوم الأخير وانتهاء المدة؛ يحفظ مع المسودة.
- من «إعدادات التجربة» أسفل الصفحة، استخدم «ملء الخطوة ببيانات تجريبية».
- في خطوة الموضوع، أدخل الرئيسي والمواضيع الفرعية ثم اضغط «حفظ الموضوع والمحكمة المختصة».
- استعرض المحكمة الواحدة أو المتعددة أو حالات الفشل من إعدادات التجربة.
- للاستئناف استخدم `01/2026/01001/1`، وللتمييز `02/2026/02001/1`.
- نتيجة الرسوم الافتراضية تعرض مبلغًا تجريبيًا قدره 78.500 د.ب. اختر «بدون رسوم» لتجربة زر التسجيل.
- الدفع لا يطلب بيانات بطاقة. تتوفر حالات النجاح والفشل والتعليق ونجاح الدفع مع تعذر التسجيل.
- «التحقق من حالة الدفع» يحاكي تسوية العملية المعلقة نفسها، ولا ينشئ عملية دفع جديدة.
- استخدم «حفظ والخروج» ثم «استكمال» لتجربة الاسترجاع.

### تجربة بيانات الأطراف

- رقم شخصي: `DEMO-ID-001` أو `DEMO-ID-002`، ثم «استرجاع البيانات من الإحصاء».
- سجل تجاري: `DEMO-CR-001` أو `DEMO-CR-002`، ثم «استرجاع البيانات من السجلات التجارية».
- هيئة حكومية: اختر الهيئة من القائمة؛ يظهر اسمها تلقائيًا.
- من إعدادات التجربة يمكن محاكاة غياب البيانات أو تعطل الاسترجاع وإعادة المحاولة.

## ما يعمل

- لوحة ملفاتي: بحث، تصفية، استكمال، وحذف المسودات.
- خمس خطوات كاملة وروابط تعديل من الملخص.
- حقول الدور الشرطية: الوكالة والجهة الحكومية.
- مرجع مستقل للاستئناف أو التمييز مع حكم تجريبي قابل للاختيار.
- موضوع طلب رئيسي واحد، وطلبات فرعية بمبالغ منفصلة، ومرجع المقابلة/الضمان مرة واحدة.
- تحديد المحكمة بعد حفظ الموضوع، واختيارها تلقائيًا إذا كانت واحدة.
- إضافة الأطراف وتعديلها وحذفها مع جدول فوري.
- إرفاق ملفات تجريبية، والتحقق الأولي من الصيغة والحجم، وتنزيل المرفقات وحذفها.
- حفظ البيانات وملفات Blob في IndexedDB، مع رصد تعارض الحفظ من نافذتين.
- مراجعة وإقرار ورسوم، وفصل الدفع عن قيد الدعوى، وإيصال تجريبي.
- تصميم متجاوب ورسائل تحقق مرتبطة بالحقول ودعم لوحة المفاتيح.

## حدود النموذج

يبدأ النموذج بجلسة eKey2 **محاكاة**. لا توجد مصادقة أو صلاحيات قضائية أو تكامل فعلي مع نظام القضايا أو الوكالات أو الدفع.

التخزين محلي على المتصفح، وليس تخزينًا مؤسسيًا أو نسخًا احتياطيًا. لا تُرسل البيانات والمرفقات إلى GitHub أو الوزارة. إزالة بيانات الموقع أو استخدام جهاز آخر لا يسترجع المسودات السابقة. استخدم بيانات ومستندات تجريبية.

القوائم والتعرفة ونتائج المحاكم وأهلية الطعن أمثلة للعرض. قواعد المدد والإعفاءات والاختصاص وصلاحية الوكالة ومتطلبات الطعون تحتاج اعتمادًا وتكاملًا قبل التنفيذ الحقيقي.

تفاصيل الحقول والافتراضات ومصادر القواعد في `MODEL-AND-RULES.md`.

## الاختبارات للمطور

Node.js 20 أو أحدث:

```text
node --test tests.cjs v1-tests.cjs mapping-tests.cjs
```

اختبارات المتصفح اختيارية للتطوير فقط. استخدمت Playwright 1.62.1 ومتصفح Edge:

```text
npm install --no-save playwright@1.62.1
node browser-tests.cjs
node browser-filing-tests.cjs
node browser-v1-tests.cjs
node browser-mapping-tests.cjs
```

شغّل خادم الملفات على المنفذ 4173 قبل اختبار المتصفح. المتغير `PROTOTYPE_URL` يغير عنوان الاختبار، و`QA_DIR` يحدد موقع لقطات التحقق، و`BROWSER_CHANNEL` يغير قناة المتصفح (الافتراضي msedge).

لا تحتاج مكتبة الاختبار لتصفح النموذج أو رفعه إلى GitHub Pages.

## روابط التقديم المباشر

يمكن إضافة الجزء التالي إلى عنوان index.html على الموقع أو إلى رابط الملف المحلي:

```text
#file?route=appeal&case=01/2026/01001/1&judgment=J-01
#file?route=cassation&case=02/2026/02001/1&judgment=J-01
```

يفحص النموذج المسار والمرجع والحكم والإتاحة قبل فتح الطلب. تُحفظ المسودة المرتبطة محليًا، ثم يزال الجزء المستهلك من العنوان لمنع إنشاء مسودة جديدة عند تحديث الصفحة. الروابط للتجربة فقط ولا تمنح وصولًا إلى قضايا حقيقية.


## ربط أنواع الطعون بالقضية الأصلية — 18 نوفمبر 2026

تعرض قائمتا الاستئناف والتمييز فقط الأنواع المرتبطة بالقضية المختارة، وتطلبان اختيارًا صريحًا. يسترجع النموذج نوع القضية والموضوع والاختصاص والطلبات السابقة. يحفظ الاستئناف مرجع الابتدائي، ويحفظ التمييز مرجعي الاستئناف والابتدائي تلقائيًا.

للتجربة: افتح استئناف القضية `01/2026/01001/1` واختر «استئناف مدني»، أو تمييز القضية `02/2026/02001/1` واختر «تمييز مدني». من إعدادات التجربة اختر «ربط أنواع الاستئناف والتمييز ← لا يوجد نوع طعن مرتبط» لفحص المنع مع استمرار حفظ المسودة.

الربط في `data.js` أمثلة فقط. يلزم اعتماد إدارة المحاكم للقائمة والعلاقات الفعلية، وإفادتنا بالإجراء عند غياب الربط. لا توجد مخاطبة آلية أو إجراءات قضائية فعلية.

اختبارات الإضافة: `mapping-tests.cjs` و`browser-mapping-tests.cjs`. توثيق القاعدة والبيانات والإجراء المطلوب في `MODEL-AND-RULES.md`، والنص الكامل للمتطلب في نهاية `SPECIFICATION.txt`.
